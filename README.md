# dsh-cost-strip

DeepSeek Harness 插件：在输入框下方常驻显示**本次对话累计花费了多少人民币**，按 DeepSeek 官方的高峰 / 空闲时段单价计算。

```
本次对话  ¥0.1234
```

鼠标悬停可看到分组明细：各模型分别花了多少、一共多少次模型调用、其中几次落在高峰时段。

## 特性

- **按消息时间戳逐条计价**，不是用「当前时间」一刀切。跨高峰、跨空闲的历史会话也能算准。
- **区分高峰 / 空闲**。高峰时段为北京时间 **09:00–12:00** 与 **14:00–18:00**（工作日），其余时间为空闲价；**周六日全天按空闲价**。
- **区分模型**，按每条消息实际使用的 `deepseek-v4-flash` / `deepseek-v4-pro` 匹配价目表。
- **读取真实用量**，来自会话快照里每条 assistant 消息上报的 `usage`，而非估算。
- 零依赖、纯前端、不联网、不上报任何数据。

## 安装

### 方式一：本地链接（开发 / 本机常驻）

```bash
# 1. 把本包 link 进你的 dsh profile
cd ~/.dsh/profiles/web
npm install link:/path/to/dsh-cost-strip

# 2. 在 profile 的 patch 层注册这一行
```

编辑 `~/.dsh/profiles/web/cordis.patch.yml`：

```yaml
- insert:
    - id: cost-strip
      name: dsh-cost-strip
```

重启 `dsh web` 即可。

### 方式二：从 npm 安装

```bash
cd ~/.dsh/profiles/web
npm install dsh-cost-strip
```

然后在同一份 `cordis.patch.yml` 里加上面的 `insert` 行。

## 价格表

单位：**元 / 百万 tokens**。

| 计费项 | V4.1 Flash 空闲 / 高峰 | V4 Pro 空闲 / 高峰 |
| --- | --- | --- |
| 输入（缓存命中） | ¥0.02 / ¥0.04 | ¥0.15 / ¥0.30 |
| 输入（缓存未命中） | ¥1.00 / ¥2.00 | ¥4.50 / ¥9.00 |
| 输出 | ¥4.00 / ¥8.00 | ¥13.50 / ¥27.00 |

价格写在 `lib/client.js` 顶部的 `PRICES` 常量里。DeepSeek 调价频繁，改价格只需改这一处，然后重启。

模型 id 不在表里时回退到 Flash 的价格档。`cacheWriteTokens` 按「缓存未命中」计价，因为 DeepSeek 没有单独的缓存写入费率。

## 已知限制

- **窗口范围**：只统计当前已加载到前端的消息。会话翻页或压缩后离开窗口的旧消息不计入。
- **估算性质**：这是按官方价目表自上而下算出的估算值，用于直观感受成本量级。实际扣费以 DeepSeek 账单为准（可能受优惠券、折扣、账户等级等影响）。
- **时区**：高峰 / 空闲按浏览器本地时间判定，设计上假设浏览器位于北京时间（UTC+8）。若你的系统时区不是 UTC+8，时段判断会有偏差。
